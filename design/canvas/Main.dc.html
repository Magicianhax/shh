How it works

Four steps, one of them yours.

01 Post Write up to 4,096 bytes, set a price and a deadline. The prompt is written into the rollup behind a read permission only you hold.
02 Claim A provider claims the job. Only then is their wallet added to the permission list, and only then can they read the prompt.
03 Answer The output is written back into the same sealed account. Its hash is recorded so nobody can swap it later.
04 Approve You read the answer and approve. The prompt is wiped, the account leaves the rollup, and the escrow pays the provider in the same Solana transaction.
What stays private

Public ledger, private words.

Everything money-related is verifiable on Solana. Everything language-related never leaves the enclave in the clear.
